# Capri + Arena: сервер на Windows и телефон из любой сети

Для новой функции нужны обновлённый сервер и отдельная сборка приложения:

- **`Capri-Arena-Screen.apk`** — сборка с отправкой скриншотов. Устанавливается **рядом** с оригинальной Capri и прежней Capri Arena, ничего удалять не нужно. Это отдельное приложение `app.capri.arena.screen`: чаты, модели и настройки из старой копии автоматически не переносятся. Для скриншотов нужен Android 11+; телефон должен поддерживать `arm64`. Обычная версия `Capri-Arena.apk` остаётся без изменений.
- **`arena-capri.bat`** — запускает на ПК сервер из этого репозитория. Сервер использует собственную авторизованную сессию пользователя Arena, а не API-ключ OpenAI или Anthropic. Для запуска нужна вся обновлённая папка репозитория, включая `arena_api` и `pyproject.toml`; одного батника недостаточно.

Соединение выглядит так: **Capri → личная сеть Tailscale + HTTPS → ПК → Arena**. На роутере порты открывать не надо; публичный Tailscale Funnel не используется. ПК и телефон могут находиться в разных сетях, но оба должны быть подключены к одной tailnet, а правила доступа tailnet должны разрешать соединение.

> Изменённая копия APK собрана из бинарного файла, поскольку исходников Android-приложения в репозитории нет. Подпись этой копии отличается от подписи оригинала. Она не обновляет оригинальную Capri и не получает её данные. Android-телефон и Windows/Tailscale в среде разработки недоступны: реальную установку и соединение на ваших устройствах нужно проверить.

## 1. Подготовка

1. Установите [Tailscale](https://tailscale.com/download) на Windows-ПК и Android. Войдите на обоих устройствах в одну tailnet и убедитесь, что VPN подключён. На Android разрешите приложению Tailscale использовать VPN и DNS.
2. Для Tailscale Serve нужны **MagicDNS** и **HTTPS Certificates** в настройках tailnet. При первом запуске Tailscale может показать ссылку для разрешения этого в браузере; выполняйте указания на экране. Выпуск сертификата публикует имя устройства и tailnet в журнале прозрачности сертификатов. Подробнее: [Tailscale Serve](https://tailscale.com/kb/1312/serve/) и [HTTPS](https://tailscale.com/kb/1153/enabling-https/).
3. Установите Python 3.10+ на ПК. Откройте `cmd` **в папке репозитория** и один раз установите зависимости:

   ```bat
   py -3 -m pip install -e ".[auto,capri]"
   ```

   Если команды `py` нет, используйте `python` вместо `py -3`. При отсутствии Chrome/Edge установите браузер Playwright: `py -3 -m playwright install chromium`.
4. Войдите в **свой** аккаунт `arena.ai` в браузере на ПК. При необходимости используйте `py -3 -m arena_api --login`, как описано в основном README. Работают только модели и лимиты, доступные вашей сессии; этот сервер сам по себе не предоставляет бесплатный доступ и не является официальным API Arena.
5. Установите `Capri-Arena-Screen.apk` на телефон и разрешите установку APK из выбранного источника. Оригинальную Capri и предыдущую Capri Arena удалять не нужно. В настройках Android → Специальные возможности включите службу **Capri Arena Screen** и подтвердите запрошенный доступ к содержимому экрана. Это отдельное разрешение от службы прежней копии.

## 2. Запуск и подключение

1. Дважды нажмите **`arena-capri.bat`** на ПК. Оставьте его окно открытым. Если Tailscale попросит включить HTTPS, перейдите по показанной ссылке и подтвердите действие, затем дождитесь готовности сервера. Возможен повторный запуск батника после включения HTTPS.
2. Батник покажет **личную строку подключения** вида `arena+https://…ts.net:8443#…` и, если установлен пакет `qrcode`, QR-код. Строка уже содержит уникальный ключ: не публикуйте её, не отправляйте в чат и не делайте общедоступных скриншотов. Сканируйте QR телефоном и скопируйте текст либо перенесите строку на телефон другим доверенным способом.
3. В **Capri Arena Screen** откройте выбор моделей → **«Добавить модель»** → **«API-ключ»**. Вставьте строку целиком, нажмите **«Подключить»** и выберите **Arena (Direct Chat)** в списке доступных моделей.
4. Напишите сообщение. Держите ПК включённым, не давайте ему уснуть и оставляйте Tailscale активным на обоих устройствах. Остановить сервер можно через `Ctrl+C` в окне батника.

Это специальная строка подключения к вашему ПК, а не ключ настоящего Anthropic. Остальные облачные провайдеры Capri остаются доступны как раньше.

## Скриншоты для Arena

Выберите в новой копии подключённую модель Arena, которая умеет принимать изображения. Когда Capri выполняет команду просмотра экрана `screen` (в том числе после поддерживаемых действий управления), приложение снимает экран через службу специальных возможностей Android и отправляет JPEG **вложением** следующего запроса Arena, а не превращает картинку в описание. На изображении добавлены небольшие номера доступных элементов для `tap|номер` и `type|номер|текст`. Снимок может содержать личные данные: его увидят ПК, Arena и выбранная модель. Изображения хранятся кратковременно в памяти приложения и не добавляются в текст запроса; код не записывает содержимое снимка в журнал сервера.

Android может запретить снимок защищённого экрана, скрыть защищённые области, либо не дать доступ к службе; в этом случае будет сообщение об ошибке, обхода защиты нет. На Android ниже 11 снимок недоступен. Старые провайдеры Capri продолжают работать по прежней схеме. Режим `echo` не проверяет, видит ли изображение настоящая модель. Установка APK и получение снимка в настоящей Arena-сессии пока не проверены на физическом телефоне и ПК.

После каждого полного ответа сервер по умолчанию запрашивает перенос созданной беседы в **архив аккаунта Arena**. В окне сервера появится строка `Arena chat archiving: enabled (background)`. Это не удаление чата и не изменение истории на телефоне. Архивация выполняется через интерфейс Arena в фоне: если вкладка занята следующим запросом, попытка может быть отложена; ошибки интерфейса или недоступность сайта могут помешать ей. Режим `echo` не обращается к Arena и ничего не архивирует. Чтобы временно оставить чаты в списке Arena, запустите `arena-capri.bat --no-archive`.

## Проверка и ошибки

- **`INSTALL_FAILED_CONTAINER_ERROR: Failed to extract native libraries, res=-18`:** в одной из прежних сборок APK были некорректные ZIP-дескрипторы; скачайте и установите обновлённый `Capri-Arena.apk`. Если ошибка повторяется, убедитесь, что на телефоне достаточно свободного места. Для диагностики полезны версия Android и журнал `adb logcat` вокруг ошибки установки. Новая Screen-сборка имеет отдельный ID и не должна требовать удаления прежних приложений. Если Android сообщает о несовпадении подписи, не удаляйте приложения с нужными данными: уточните, какой APK установлен и какая именно ошибка показана.
- Чтобы проверить соединение без запроса к Arena, запустите в `cmd` команду `arena-capri.bat --engine echo`. В этом режиме сервер возвращает полученный текст, а не ответ нейросети. После проверки остановите его и запустите обычный `arena-capri.bat`.
- **Tailscale не найден/не подключён:** установите и запустите Tailscale на ПК; если CLI установлен не в стандартной папке, можно указать его полный путь в переменной `ARENA_CAPRI_TAILSCALE`.
- **«Ключ не распознан»:** в Capri эта общая ошибка может означать и неверный ключ, и недоступный сервер. Проверьте строку целиком, включённый VPN на обоих устройствах, MagicDNS/HTTPS и окно сервера на ПК.
- **Порт 8443 занят в Tailscale Serve:** сервер не меняет чужую настройку. В `cmd` выберите свободный HTTPS-порт и запустите батник в том же окне:

  ```bat
  set ARENA_CAPRI_HTTPS_PORT=443
  arena-capri.bat
  ```

  После изменения порта вставьте в Capri новую показанную строку подключения. Локальный порт сервера по умолчанию — 8082, его можно изменить переменной `ARENA_CAPRI_PORT`.
- Если ответов нет, сначала проверьте режим `echo`, затем авторизацию в Arena и сообщение об ошибке в окне ПК. Первый ответ после запуска браузера может занять заметное время. Не отправляйте в чат свои cookies или ключ подключения.

## Безопасность

- Обычный `arena-api --claude` **не проверяет ключи** и предназначен для loopback. Не выставляйте его напрямую на `0.0.0.0` или в интернет. Батник запускает отдельную обёртку: она слушает только `127.0.0.1`, проверяет случайный ключ и публикует сервис только через приватный Tailscale Serve с HTTPS.
- Ключ создаётся один раз и сохраняется в игнорируемом Git файле `state/capri-key.txt`; на Windows доступ к нему определяется правами папки пользователя. В Capri строка хранится в приватных настройках приложения. Пользуйтесь только доверенным телефоном и ПК.
- Если строка утекла, остановите сервер, удалите `state/capri-key.txt` на ПК, снова запустите батник и подключите новую строку в Capri. Старая перестанет работать.
- Когда вы пользуетесь облачной моделью, текст запросов и контекст отправляются через ПК в Arena. Дополнительные действия Capri на телефоне и её разрешения — отдельные функции приложения; разрешайте их только если доверяете приложению.

## Пересборка APK для разработчика

Для исходного `Capri.apk` версии 1.22 (SHA-256 `81cb3378d64bd06e0d7eee8df512742e13b461635030e1b318d225cb2f741b22`) нужны JDK, Apktool 2.9.3 и Android SDK Build Tools с `zipalign` и `apksigner`:

```text
java -jar apktool.jar d -f Capri.apk -o capri-decoded
python tools/patch_capri.py capri-decoded --screenshots
java -jar apktool.jar b capri-decoded -o capri-unsigned.apk
zipalign -f 4 capri-unsigned.apk capri-aligned.apk
apksigner sign --ks YOUR_PRIVATE_KEYSTORE --out Capri-Arena-Screen.apk capri-aligned.apk
apksigner verify --verbose Capri-Arena-Screen.apk
zipalign -c -v 4 Capri-Arena-Screen.apk
python -m pytest -q tests/test_capri_apk.py
```

Используйте официальную `zipalign` из Android SDK. Тест проверяет не только распаковку и выравнивание, но и согласованность ZIP-заголовков и data descriptors: Android может отвергнуть APK, который обычная проверка CRC считает исправным.

Используйте собственный закрытый ключ подписи и не добавляйте его в Git. Готовые APK подписаны отдельными ключами, которые не распространяются в репозитории; пересобранный другим ключом APK нельзя установить как обновление соответствующей копии. Удаление любой установленной копии приложения удалит именно её локальные данные. Для будущих собственных сборок сохраните свой закрытый ключ в безопасном месте.
